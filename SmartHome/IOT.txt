Humanoid Robot Hardware Blueprint:
==================================
1️⃣ Main Compute (Robot Brain)
Component		    		Example            				         Why 
Edge AI computer   NVIDIA Jetson Orin Nano Developer Kit    		Run AI models locally
Microcomputer           Raspberry Pi 5                   	     Robot control and networking

💡 Most robots use Jetson for AI + Raspberry Pi for system control.

2️⃣ Vision System (Robot Eyes)
Component					Example									 Why
RGB camera			Intel RealSense D435i						    Object detection
Depth sensor			Intel RealSense D455					    3D environment mapping

These enable:
object recognition
distance estimation
obstacle detection

3️⃣ Audio System (Robot Ears)
Component					Example									Why
Microphone array		ReSpeaker 4-Mic Array for Raspberry Pi		  Voice commands
Speaker					generic speaker module					 Robot speech output

Used for:
speech recognition
human interaction

4️⃣ Motion System (Robot Body)
Humanoid robots require many actuators.
Component					Example									Why
Servo motors				Dynamixel XM430-W350					Precise joint movement
Motor controller		Pololu Maestro Servo Controller					Control multiple motors

Typical humanoid robot:
12–20 servo motors
joints for arms, legs, head

5️⃣ Sensors
Sensor						Example									Why
IMU							Bosch BNO055							Balance
Lidar						RPLIDAR A1M8							Mapping
Touch sensors					force sensors								Object manipulation

These allow the robot to:
balance

detect contact
